# Design System

## Overall Style

The application should feel like a modern booking SaaS product.

Visual characteristics:

- Clean
- Minimal
- Professional
- Spacious
- Modern
- Easy to scan

Avoid:

- Excessive gradients
- Excessive animations
- Huge rounded cards
- Too many colors
- Excessive shadows
- Decorative elements that do not improve usability

## Spacing

Use a consistent spacing system.

Prefer:

- p-4
- p-6
- p-8
- gap-4
- gap-6
- gap-8

Avoid arbitrary spacing unless necessary.

## Cards

Cards should:

- Have subtle borders
- Use moderate border radius
- Avoid heavy shadows
- Have consistent padding

Example:

<Card className="rounded-xl border shadow-sm">
